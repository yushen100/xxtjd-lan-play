# 小小突击队联机部署：房主与好友下载教程

支持 Windows 10/11 64位。真实跨电脑对局仍待验；当前已通过本机协议回归、百人合成压测和重复开服检查。

| 自己开服，也能加入别人的房间 | [完整包：包含房主端和好友端](https://github.com/yushen100/xxtjd-lan-play/releases/tag/play-full-2026-10-11-v4) |
| 只加入朋友的服务器 | [好友专用包：不能开服](https://github.com/yushen100/xxtjd-lan-play/releases/tag/play-friend-2026-10-11-v4) |

两套都含客户端、资源、补丁工具、Radmin VPN安装器；完整包还含服务器、Python和验收工具。无需安装Git、Codex，不用另找微端。好友包没有服务器或角色数据库，存档保存在房主电脑。

各套独立说明：[完整包 README](content/1011_完整包README_v4.md)、[好友包 README](content/1011_好友包README_v4.md)。详细参考：[玩家联机指南](content/1011_玩家联机指南_v4.md)。完整包约746MiB、好友包约734MiB，各26卷；v4两套包正在上传，发布完成前下载链接可能显示404。

这是干净的公开发布仓库，可直接下载，无需申请权限。GitHub自动附带的Source code不是游戏运行包。

## 下载与解压（两端都要做）

1. 打开所选Release，展开Assets。
2. 完整包下载所有 `1011_rea_full_v4_*.zip`、`1011_full_parts_v4.json`、`1011_extract_full_v4.ps1`、`1011_extract_full_v4.bat`。好友包下载所有 `1011_rea_friend_v4_*.zip`、`1011_friend_parts_v4.json`、`1011_extract_friend_v4.ps1`、`1011_extract_friend_v4.bat`。不要混用两套。
3. 放在数据盘同一个目录，例如 `D:\小小突击队下载\`。分卷必须全部下载，保留原文件名；不需要拼接或手动逐卷解压，也不用下载旧v1/v2。
4. 双击对应BAT。入口先校验所有分卷，再解压并核对包内文件，生成 `REA完整联机版_v4` 或 `REA好友端_v4`。提示缺卷或损坏时只重下指出的文件。目标目录已有内容会停止，请用新目录，避免覆盖存档。
5. 预留至少5GB空闲空间，包含下载包、解压结果及首次启动生成的客户端副本。看到完成提示再运行包内 `一键启动` 文件夹的入口。

## 先建立网络

**同一局域网：** 双方连接同一个路由器网络，房主在命令提示符执行 `ipconfig`，使用当前网卡的IPv4（常见192.168.x.x或10.x.x.x）。不能给好友127.0.0.1；访客Wi-Fi可能隔离设备。

**异地：** 双方运行 `一键启动/0_安装RadminVPN(异地联机).bat`，本人完成安装与许可确认；已安装可跳过。在Radmin VPN中房主创建网络，好友加入同一网络。网络名和密码私下告知好友；确认双方在线，记下房主顶部的26.x.x.x地址。Radmin界面按钮以实际版本为准。

不用路由器公网端口映射。所有玩家应使用同一版包。房主开服期间保持电脑和Radmin运行。

## 房主开服（完整包）

1. 双击 `一键启动/0_检查部署.bat`，确认依赖和资源通过检查。
2. 同一局域网运行 `一键启动/1_房主开服(局域网).bat`；异地运行 `一键启动/1b_房主开服(虚拟局域网).bat`。输入房主自己的局域网IP或Radmin的26.x地址，以及账号名。
3. 账号名为2–16位字母、数字、下划线，每人使用不同名称。账号没有独立密码，请只和可信朋友联机。
4. 允许服务的TCP 18798、18799、18800入站。防火墙规则要覆盖实际局域网/Radmin网卡和所需地址范围；Radmin网卡可能被识别为公共网络，不能只勾“专用网络”就认定已放行。
5. 把房主IP告诉好友。进入游戏后创建房间，等待好友加入和准备，再选人、加载、打一局。重复运行入口应复用已有服务。

## 好友加入（好友包或完整包）

1. 先确认房主已开服、双方在同一网络中在线。
2. 双击 `一键启动/2_好友加入.bat`，填写**房主**IP和自己独有的账号名，不要填自己的IP。
3. 首次运行会复制包内客户端并打补丁，可能需要几分钟；等待完成。无需运行房主开服入口。
4. 进入房主的房间，准备、选人并完成一局。双方核对结算，退出后重新加入确认存档；这些属于实际联机验收，仍需要两台电脑确认。
5. 更换房主IP前关闭本工具启动的客户端，再重新运行入口。重复启动同账号会复用已有窗口。

## 连不上时

| 现象 | 检查 |
| --- | --- |
| Release打开404 | GitHub是否登录且有私有仓库访问权限 |
| 解压报缺卷/损坏 | 下载同一套所有ZIP及JSON、PS1、BAT，保持文件名，重下明确报错的文件 |
| 连不上正确的房主服务 | 房主已开服、IP正确、Radmin同网络在线、18799入站放行 |
| 能登录但战斗卡住 | 单独检查18800；双方使用同一版资源和补丁 |
| 地址被拒绝 | 使用局域网IP、Radmin 26.x或Tailscale 100.64–127.x；不使用普通公网IP |
| 客户端原件/程序集校验失败 | 重新解压干净包，不混用其他版本DLL；保留错误输出 |
| 已有不同地址/版本的服务运行 | 让玩家退出并备份存档，再用完整包的停止服务工具停本项目服务，重新开服 |

在好友电脑PowerShell运行以下命令，把 `房主IP` 替换为实际地址：

```powershell
Test-NetConnection 房主IP -Port 18798
Test-NetConnection 房主IP -Port 18799
Test-NetConnection 房主IP -Port 18800
```

三项 `TcpTestSucceeded` 应为True；只证明端口可连接，还需游戏对局验证。房主日志在 `memory/1010_本地私服日志_v1/`，角色库在 `drafts/1010_本地私服_v1/1010_角色数据库_v1.sqlite3`。不要运行中只复制SQLite主文件；使用完整包的在线备份工具。更新到新目录不自动迁移旧存档。


## 这次修复了什么

- 同局结算唯一记录覆盖货币、材料、战绩、战报、宝箱和通行证经验。失败整体回滚，重复请求不会重复发完整奖励。
- 战报按实际真人名单等待报齐，再判断多数 / 最终平票；前两份临时 1:1 不会把三人对局提前判成争议。
- 宝箱按本局 ID / 槽位 / 已领取物品追踪。回收余额不足时记入 `reward_recovery_pending`，不再悄悄当成全部收回。
- 多房间同一轮关键帧批量提交，提交成功后才广播；每连接独立有界发送队列，接收过慢的客户端不会拖住所有房间。
- 服务器与客户端补丁共用网络配置，统一接受局域网、Radmin 26/8、Tailscale 100.64/10。
- 房主入口复用已有服务、好友入口复用同账号窗口；地址、补丁或代码版本变化会给出明确提示。不会按一个文件名停止其他项目的 Python 服务。
- 带免安装 Python，启动前检查依赖和资源；`/health` 给出实际运行的代码指纹，避免把旧进程误当成新版。

## 百人承载证据

本机 Windows 11，12 个逻辑 CPU；服务端和合成客户端运行在同一台电脑。100 名玩家同时保持大厅和战斗两条 TCP 连接，10 个十人房间，持续 30Hz 输入约两分钟。

| 指标 | 本次实测 |
| --- | --- |
| 玩家 / TCP 连接 | 100 / 200 |
| 战斗时长 | 120.78 秒 |
| 最低输入频率 | 30.0 Hz / 人 |
| 输入总数 | 362,300 |
| 最低关键帧率 | 29.87 / 秒，目标 30 |
| 帧到达间隔 P95 | 47.0 ms |
| 请求延迟 P95 | 140.0 ms，含登录、房间、心跳和结算 |
| 结算请求 P95 | 328.0 ms |
| 帧调度迟到 | 6 次 |

通过：100 人登录、分房战斗、帧连续、断线重连补帧、100 人结算、重复结算无重复奖励、SQLite 完整性。详细证据见[百人报告](content/1011_百人承载验收_v1.json)。这是协议承载测试，尚未覆盖 100 台真实电脑、实际 VPN 带宽、同时下载资源或长时间运行，不承诺所有硬件都能复现同样指标。

## 一键复验

`工具_运行隔离验收.bat` 运行经济、成长、房间、帧调度、原生协议、双端 TCP 和可靠性测试。`工具_百人压测.bat` 再加两分钟、每人 30Hz 输入的百人测试，建议空闲时运行。

```powershell
.\tools\python\python.exe .\scripts\1010_本地私服_v1\1011_可靠性验收_v1.py
.\tools\python\python.exe .\scripts\1010_本地私服_v1\1011_百人承载验收_v1.py --seconds 120 --input-hz 30
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\1011_启动复用验收_v1.ps1 -PythonPath "$PWD\tools\python\python.exe"
```

所有自动验收使用独立测试库。启动复用验收在独立目录使用 28798–28800，已在 Windows PowerShell 5.1 连续运行两次，确认同一进程拥有三个端口；游戏窗口和跨电脑对局仍待验。失败数据库和日志会保留，便于定位和重试。

## 存档和更新

存档：`drafts/1010_本地私服_v1/1010_角色数据库_v1.sqlite3`。日志：`memory/1010_本地私服日志_v1/`。开服和每六小时自动在线备份，保留最近十二份；可运行 `工具_备份角色存档.bat` 另做在线备份。

更新先备份存档、让玩家退出，再运行 `工具_停止本项目服务.bat`，覆盖新代码后开服。启动入口会核对 `/health` 的代码指纹，旧代码进程不会被误报为更新成功。换新电脑默认新建存档；迁移旧存档使用在线备份，不能运行中仅复制 SQLite 主文件。

| `scripts/1011_网络规则_v1.json` | 所有入口共用的地址白名单 |
